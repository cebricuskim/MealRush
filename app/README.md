# MealRush 🍴

**Food Delivery Android App**

## 📖 Overview
MealRush is an Android application designed to simplify food delivery.  
It allows users to browse menus, place orders, and track deliveries in real time.

## 🚀 Features
- User-friendly interface for browsing restaurants
- Secure order placement and payment
- Real-time delivery tracking
- Profile and order history management

## 🛠️ Tech Stack
- **Language:** Java / Kotlin
- **IDE:** Android Studio
- **Version Control:** Git + GitHub
